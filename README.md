# HTML Course Registration

An introductory HTML project with semantic content, links, images and a course registration form. Uses native required-field validation and a nine-digit course-code pattern. No backend or persistent registration service is included.

## Authors

Developed by **Noor Salah** and **Amer Abu Sair** as university coursework. This is an independent portfolio copy; the original Classroom submission is preserved.

## Run locally

From this directory, run:

```sh
python -m http.server 8000
```

Open http://localhost:8000. Internet access is needed for externally hosted assets and APIs.

## Portfolio copy

Course grading reports, IDE metadata and personal contact details are excluded or replaced with example values.
